# MYOKOスイーツ プロジェクト

妙高高原・野尻湖エリアのスイーツ情報を発信するWEBサイト＆SNSのプロジェクト管理リポジトリ。

## プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | MYOKOスイーツ |
| 対象エリア | 妙高高原・野尻湖エリア |
| ターゲット | 国内観光客・地元住民・インバウンド |
| 運営体制 | 個人運営 |
| 収益モデル | Google AdSense（PV重視） |
| WEBサイト | WordPress予定 |
| SNS | Instagram / X / TikTok・YouTubeShorts |
