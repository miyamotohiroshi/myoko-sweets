## Claude Chatへの申し送り事項
- サイトはまだ公開しない前提。各お店に自分のページを確認してもらう「プレビューだけ見える」仕組みは、あとで作る
- 写真の掲載許可は、各お店にこれから取る
- 仮画像は撮影後に差し替える（メディアの「【仮画像】」で検索すると一覧できる）

## 気になった点・懸念点
- メニューは Excel の「代表スイーツ・価格」欄から自動で分けたため、一部が粗い（例：越後姫が定番と限定の両方に出る）。「要確認」の品はメニューに入れていない
- 店舗ラベルとキャッチコピーは自動で作った文なので、見直しが必要
- 店舗の位置情報（緯度経度）が未入力のため、「近くのスポット」が出ない
- 限定スイーツ欄（menu_sweets_limited）の入力説明が、コピー元の文のまま
- コード変更（メニューの定番／季節限定）はまだコミットしていない
