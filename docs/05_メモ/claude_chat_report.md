## Claude Chatへの申し送り事項
- アップロード前に `chmod -R a+rX web/public web/out` で権限をそろえる（Mac の rsync は権限を変える指定ができないため）
- WordPress のドリンク・お食事メニュー欄の説明文が「HTMLで入力」のままになっている。実際は「商品名 | 価格」の1行1品で入力できるので、説明文を直すとよい
- メニュー写真にあったハーブティーの説明文や「ドリンクは持ち帰り可」は、入れる欄がないため未登録
- 02_メインのお店・04_ドリンク・05_人気スイーツ・06_人気食事は、今ある写真に該当する分類がないため空。「メインのお店」に何を入れるか（WordPress の「お店の雰囲気写真」か）を確認したい
- 写真を追加・差し替えるときは、分類フォルダと店フォルダ直下の両方を更新する必要がある
- 99_未使用 は8分類にない写真（食事・重複など）の置き場として追加した。不要なら削除してよいか確認
- 正式公開するときは、SITE_OPEN を true にする・.htaccess の認証ブロックを消す・サーバーキャッシュの2行を元に戻す、の3つが必要
