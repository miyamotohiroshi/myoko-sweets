# SNS 運用ルール

## Instagram

### 投稿フォーマット
- 画像：1:1 正方形 or 4:5 縦長
- キャプション構成：
  1. 一行目：目を引く一言（例：「妙高高原で出会った絶品モンブラン🍂」）
  2. 店舗名・場所
  3. 詳細説明（2〜3行）
  4. 英語キャプション（インバウンド向け・短文でOK）
  5. 改行してハッシュタグ

### ハッシュタグ（テンプレ）
```
#妙高高原 #野尻湖 #妙高スイーツ #新潟カフェ #高原カフェ
#MYOKOsweets #NojirikoLake #NiigataSweets #JapanCafe
```

### 投稿禁止事項
- 無断で店舗の内部・スタッフを撮影した写真
- 価格の誤情報
- 他アカウントのコンテンツの無断転載

## X（旧Twitter）

### 投稿スタイル
- 短文＋写真1枚が基本
- WEB記事の更新告知に活用
- 地元イベント情報のリツイートもOK

## TikTok / YouTubeShorts

### 動画フォーマット（予定）
- 尺：30〜60秒
- 構成：店舗外観 → スイーツのアップ → 食べるシーン → テロップで情報
- BGM：著作権フリー音源を使用
