# Claude Code 行動ルール｜MYOKOスイーツ プロジェクト

このファイルはClaude Codeが自動的に読み込むルール設定ファイルです。
以下のルールに従って作業を進めてください。

---

## プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | MYOKOスイーツ |
| 対象エリア | 妙高高原・野尻湖エリア |
| ターゲット | 国内観光客・地元住民・インバウンド |
| 運営体制 | 個人運営 |
| 収益モデル | Google AdSense（PV重視） |
| WEBサイト | WordPress予定 |
| SNS | Instagram / X / TikTok・YouTubeShorts |

---

## 作業完了時の必須アクション

ひとつの作業が完了したら、必ず以下を実行すること。

### 1. タスク管理ファイルのステータスを更新する

該当タスクのステータスを以下の凡例に従って更新すること。

- 🔴 未着手
- 🟡 進行中
- 🟢 完了
- ⏸️ 保留

### 2. レポートファイルを更新する

`docs/05_メモ/claude_chat_report.md` を以下のフォーマットで更新すること。
（ファイルがなければ新規作成する）

---

## レポートフォーマット

`docs/05_メモ/claude_chat_report.md` に以下の内容を記載すること。

```
# Claude Chat 引き継ぎレポート

## 作業日時
（作業した日時を記載）

## 今回完了したタスク
- （完了したタスクをリストで記載）

## 作成・変更したファイル
| ファイルパス | 変更内容 |
|---|---|
| （パス） | （何をしたか） |

## タスク管理の更新内容
| ファイル | タスク名 | 変更前 | 変更後 |
|---|---|---|---|
| （ファイル名） | （タスク名） | 🔴 未着手 | 🟢 完了 |

## Claude Chatへの申し送り事項
- （Chatで相談・確認すべきことをリストで記載）

## 次のステップ提案
- （次にやるべきことをリストで記載）

## 気になった点・懸念点
- （エラー・不明点・確認が必要なことを記載）
```

---

## 作業中のルール

1. **確認を優先する**：大きな変更・削除の前は必ず確認を取ること
2. **ステータスをこまめに更新**：タスク完了のたびにmdファイルを更新する
3. **エラーは記録する**：エラーが発生したら原因・対処法をレポートに残す
4. **日本語で記載**：レポートやコメントはすべて日本語で記載する

## Claude Chatへの引き継ぎ手順

作業終了時またはClaude Chatに戻るときは、以下を実行すること。

1. `docs/05_メモ/claude_chat_report.md` を最新状態に更新する
2. ユーザーに「レポートを更新しました。Claude Chatに `claude_chat_report.md` をアップロードして続きを相談してください。」と伝える
