## 1. プロジェクトの背景・WHY NOW

### 地域の現状
- 妙高高原・野尻湖エリアはスキー場を中心とした観光地だが、近年は過疎化が進行
- 一方でインバウンド（外国人旅行者）の増加により、冬季を中心に盛り上がりを見せている

### 2028年に向けた大きな変化
シンガポールの投資ファンド「ペイシャンス・キャピタル・グループ（PCG）」が
総額約2000億円を投じて妙高高原エリアで大規模なメガリゾート開発を進めている。
2028年冬の開業に向けて、スキー場を中心とした滞在型リゾートへのリニューアルが進行中。

### なぜ今メディアを作るのか
- 2028年のリゾート開業に合わせ、国内外の観光客が急増することが予測される
- SEO・SNSは結果が出るまでに1〜2年かかるため、今から仕込むことが重要
- 「妙高スイーツといえばここ」というポジションを2028年までに確立する
- 地元で自営業をしている友人たちのビジネスを支援するプラットフォームにもなる
- 将来的に自分が妙高で飲食店・バー・Airbnbなどを始めた際、メディアが強みになる

## 3. ターゲット

| ターゲット | 特徴 | 主な接触点 |
|---|---|---|
| 国内観光客 | 妙高・野尻湖を旅行中にスイーツを探している | Google検索 → WEB記事 |
| 地元住民・リピーター | 地元カフェ・お菓子屋の情報を定期的に見に来る | Instagram・X |
| インバウンド（外国人） | SNSでスイーツ・カフェを探す外国人旅行者 | Instagram・Google Maps |

### ターゲットの行動パターン（観光客）
1泊2日の旅行者が妙高に来た際の行動：
- チェックイン前の空き時間（昼前後）→ カフェ・スイーツを探す
- チェックアウト後の時間 → 帰り道のカフェ・スイーツを探す
- 夕ご飯は宿泊先で済むことが多い → 昼〜おやつ時間のニーズが高い

**このすき間時間にスイーツ・カフェ情報を探している人々をすくい上げる。**

## 4. ポジショニング戦略

### 競合との関係性

```
Googleマップ ──── 近くのお店を「見つける」
食べログ     ──── 評価・口コミを「確認する」
                    ↑
         この2つの間を行き来している観光客
                    ↓
  MYOKOスイーツ ── 妙高エリアに特化した
                   「地元目線の信頼できるガイド」
                   ＋ Googleマップ・食べログへのハブ
```

### E-E-A-Tを活かした差別化
Googleが重視するE-E-A-T（経験・専門性・権威性・信頼性）の観点で、
個人メディアが勝てる領域に特化する。

- **Experience（経験）**：地元在住・実際に食べ歩いた一次情報
- **Expertise（専門性）**：妙高・野尻湖エリアのスイーツに特化
- **Authoritativeness（権威性）**：地域唯一のスイーツ専門メディア
- **Trustworthiness（信頼性）**：Googleマップ・食べログへの誠実なナビゲーション

### 地方メディアの強み
地方の飲食店情報は食べログの書き込み総数が少ない。
地元の人間が実際に食べて書いた情報が、最も信頼される。

## 5. サービス仕様

### メインコンテンツ：スイーツ・カフェ情報

#### 掲載エリア
- 妙高高原エリア
- 野尻湖エリア
- 周辺（随時拡張）

#### カテゴリ
- アイス
- ケーキ
- パフェ
- クレープ
- ジェラート
- 和菓子
- 地元食材スイーツ

#### 店舗一覧UI仕様
- 画像：メイン（左50%）＋サブ（右50%）の横並び
  - 左メイン：そのお店のメインスイーツ写真
  - 右サブ：お店の雰囲気写真
- その下に4枚並びのサムネイル（右スクロールで追加画像を表示・タップで拡大）
- カテゴリ絞り込み時：そのカテゴリの商品写真がメイン画像として表示される
  （例：アイスで絞り込んだ場合、アイスが主力でない店舗もアイス写真を表示）

#### 季節営業フィルター
妙高・野尻湖エリア特有の季節営業に対応：
- 冬季のみ営業の店舗
- グリーンシーズン（夏季）のみ営業の店舗
- 現在の月に営業しているお店のみを表示する機能

#### Googleマップ・食べログ連携
- 各店舗ページにGoogleマップへのリンクを設置
- 食べログへのリンクを設置
- ハブとして機能し、ユーザーが行き来しやすいUIを実現

### サブコンテンツ：特集記事
メインのスイーツ情報に加え、以下の特集記事を展開：
- ランチ情報
- 夕ご飯情報
- 観光スポット情報
- モデルプラン（1泊2日など）
- スキー場情報
- ホテル・民宿・民泊情報
- 旅行好きな運営者ならではの切り口で妙高の良さを発信

### 多言語対応
- 日本語・英語の多言語切り替え（フェーズ2から実装）
- 将来的にインバウンド向け情報を充実させる

## 6. 技術スタック

### 構成
**ハイブリッド構成**（ヘッドレスWordPress ＋ Next.js）

```
WordPress（コンテンツ管理）
　記事入力・店舗情報管理・画像管理
　REST APIでデータを配信
        ↓
Next.js（フロントエンド）
　表示・UI・フィルター・多言語・速度
　Vercelでホスティング
```

### 採用技術

| 項目 | 技術 | 理由 |
|---|---|---|
| CMS | WordPress（ヘッドレス） | 使い慣れている・記事入力が楽 |
| データ取得 | REST API（WordPress標準） | 設定が簡単・実績が多い |
| フロントエンド | Next.js | React経験を積める・SSGで高速 |
| 言語 | TypeScript | 店舗データの型定義が安全 |
| スタイル | Tailwind CSS | ブランドカラー変数化が楽 |
| ホスティング（フロント） | Vercel（無料枠） | Next.jsと相性最高・CDN対応 |
| ホスティング（WP） | 既存レンタルサーバー | コスト削減 |

### 採用理由
- WordPressのフロントを作ってしまうと、後からNext.jsへの移行時に全て作り直しになる
- 最初からハイブリッドで構築することで二度手間を防ぐ
- AIを使って実装する場合、最初からNext.jsで一貫したコードを書く方が効率的
- 2028年のインバウンド対応に向けて、速度・UIを最初から作り込む
